# 🚀 CareerForge - All-in-One Job Portal & Tech Interview Prep Ecosystem

CareerForge is a comprehensive web platform combining an active **Job Portal** with structured **Technical, Aptitude, DSA, and HR Preparation Modules**, alongside **Company-Specific Hiring Playbooks**.

---

## 🌟 Key Features

### 1. 💼 Tech Job Portal
- **Rich Job Listings**: Filter by Category (Software Engineering, Frontend, Backend, AI/ML, Cloud/DevOps, Data), Experience (Fresher, 0-2 yrs, 1-3 yrs), and Mode (Full-Time, Remote, Hybrid, Internship).
- **Fast 1-Click Application**: Pre-fills verified student profile details, resume upload/switch, custom pitch to recruiter, and generates real-time application pipeline tracker.
- **Bookmarks & Saved Jobs**: Save dream opportunities for later review with persistent localStorage.
- **Deep Job View**: Full responsibilities, requirements, CTC breakdown, perks, and direct cross-link to the target company's hiring exam guide!

### 2. 🧠 Preparation Hub (`/prep`)
- **Quantitative Aptitude**: High-yield formulas, speed math shortcuts, Time & Work, Speed Distance Time, Percentages, and interactive timed quizzes with step-by-step mathematical explanations.
- **Logical Reasoning**: Syllogisms, Venn deductions, Blood relations, with practice questions and instant feedback.
- **Verbal Ability**: Subject-verb agreement, modifiers, vocabulary flashcards, and sentence correction.
- **Core Technical CS**:
  - **Operating Systems**: Processes vs Threads, Coffman Deadlock conditions, Virtual Memory, Paging, Thrashing, and interview questions.
  - **DBMS & SQL**: Relational modeling, Normalization (1NF to BCNF), ACID transactions, B-Tree indexes, and Nth highest salary queries.
  - **Computer Networks**: OSI 7-layer model, TCP 3-way handshake, DNS query lifecycle, TCP vs UDP.
  - **System Design & LLD**: CAP theorem, Caching strategies (Cache-Aside, Write-Through), Database Sharding, and URL Shortener architecture.
- **HR & Behavioral Prep**:
  - The **STAR Method** (Situation, Task, Action, Result) interactive breakdown with percentage allocations.
  - Model responses for top HR questions (Tell me about yourself, technical disagreements, failures, weaknesses).
  - Smart questions to ask the interviewer at the end of the interview.

### 3. 🏢 Companies Hiring Process (`/companies`)
- **Deep Exam Guides** for Google, Amazon, Microsoft, TCS (Ninja/Digital/Prime), Infosys (SE/DSE/Specialist Programmer), Accenture, etc.
- **Round-by-Round Breakdown**: Duration, platform (HackerRank, iON, Wheebox, Meet), format, and passing criteria.
- **Detailed Syllabus**: DSA topics weightage, core CS requirements, and aptitude requirements.
- **Eligibility Criteria**: CGPA cutoffs, active and history of backlogs policy, permissible education gap years, and eligible branches.
- **Previous Year Trends & Questions**: Real algorithmic and interview questions asked in recent placement seasons.
- **Direct Link to Practice**: 1-click button to filter DSA problems specifically asked at that company.

### 4. ⚡ Dedicated Topic-Wise DSA Sheet (`/dsa`)
- SDE Sheet organized into core topics:
  1. Arrays & Hashing
  2. Two Pointers & Sliding Window
  3. Linked Lists
  4. Binary Trees & BSTs
  5. Dynamic Programming
  6. Graphs & BFS/DFS
- **Multi-Language Solutions**: Ready-to-copy, syntax-formatted solutions in **Python**, **C++**, **Java**, and **JavaScript**.
- **Intuition & Complexity**: Big-O Time & Space analysis and optimal algorithmic steps.
- **Personal Problem Notes**: Save custom notes, learnings, and edge cases directly in your browser.
- **Interactive Progress Tracking**: Checkboxes with real-time analytics bar (% solved, easy/medium/hard breakdown).
- **Direct External Links**: Practice directly on LeetCode and GeeksForGeeks.

### 5. 📊 Candidate Dashboard & Status Pipeline (`/dashboard`)
- **Application Status Pipeline**: Submitted → Under Review → Interview Scheduled → Offer Received.
- **DSA Progress Analytics**: Visual completion percentage and difficulty breakdown.
- **Quiz Performance History**: Log of past aptitude and technical quiz scores.
- **Profile Management**: Update target role, college, CGPA, graduation year, and degree.

## 🛠️ Tech Stack

- **Frontend**: React 18 / Vite
- **Styling**: Tailwind CSS (Dark tech theme with glassmorphism effects)
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **State Management**: React Context API with LocalStorage persistence

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```
